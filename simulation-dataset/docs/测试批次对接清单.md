## 3. 评测口径（最容易踩坑的三点）

1. **输入预处理必须复用** `cnn-inversion/src/data.py` 的 `load_image()`：
   `/255` 之后再**逐图 z-score**（减本图均值、除本图标准差）。自己写 `/255` 会让稀疏
   POM 纹理几乎不可学——这是 ① 任务从 acc 0.00 抬到 1.00 的关键。
2. **分类**：类别表取 `runs/mixed_pitch_final/meta.json` 的 `classes`（11 类，30–40），
   `argmax` 得到索引再映射回 η。
3. **回归**：模型输出是**标准化值**，必须用对应 `meta.json` 的 `label_mean` / `label_std` 反变换：
   - 电压 → `runs/mixed_voltage/meta.json`
   - 自由能 → `runs/mixed_energy/meta.json`

   平台模型的 `platform/predictor.py` 用的就是这两个文件，口径完全一致；补训模型
   （`runs/supplement_*`）目录里只有 `metrics.json`、没有 `meta.json`，反标准化参数沿用上面两个基准。

**指标建议**：分类报 accuracy + 混淆矩阵；回归报 R²、MAE、RMSE，**以 MAE 为主**
（自由能量级 ~1e-13，MSE 数值小到没有直观意义）。

## 4. 可直接用的评测脚本

把下面存成 `cnn-inversion/src/eval_testbatch.py`，在 `cnn-inversion/` 下运行
`python src/eval_testbatch.py`。它按 `kind` 分组统计，便于你区分单/双 toron。

```python
# -*- coding: utf-8 -*-
"""用 testbatch_20261026 评测既有模型（B 侧脚本，A 未在此环境跑过 TF）。"""
import json
from pathlib import Path

import numpy as np
import pandas as pd
import tensorflow as tf

from data import make_dataset

ROOT = Path(__file__).resolve().parents[1]                 # cnn-inversion/
BATCH = ROOT.parent / "simulation-dataset" / "outputs" / "testbatch_20261026"
df = pd.read_csv(BATCH / "labels" / "labels_testbatch_mixed.csv")
paths = [str(BATCH / "pom_images" / f) for f in df["filename"]]

def make_ds():
    # labels 占位即可（预测阶段不使用）；make_dataset 内部会做 load_image 的 z-score
    return make_dataset(paths, np.zeros(len(paths), dtype=np.float32), 32, training=False)

def predict(run):
    meta = json.loads((ROOT / "runs" / run / "meta.json").read_text(encoding="utf-8"))
    model = tf.keras.models.load_model(ROOT / "runs" / run / "model.keras", compile=False)
    return model.predict(make_ds(), verbose=0), meta

# ---- 分类：螺距 η ----
classes = json.loads((ROOT / "runs/mixed_pitch_final/meta.json").read_text(encoding="utf-8"))["classes"]
prob, _ = predict("mixed_pitch_final")
pred_eta = np.array([classes[i] for i in prob.argmax(1)])
eta = df["eta"].to_numpy()
print(f"[pitch] acc={np.mean(pred_eta == eta):.4f}  n={len(eta)}")
for kind in ("single", "double"):
    m = (df["kind"] == kind).to_numpy()
    print(f"   {kind}: acc={np.mean(pred_eta[m] == eta[m]):.4f}  n={m.sum()}")

# ---- 回归：电压 / 自由能（必须反标准化）----
def report(name, run, col):
    pred, meta = predict(run)
    y = pred.ravel() * meta["label_std"] + meta["label_mean"]
    t = df[col].to_numpy(dtype=float)
    r2 = 1 - ((t - y) ** 2).sum() / ((t - t.mean()) ** 2).sum()
    print(f"[{name}] R2={r2:.4f}  MAE={np.abs(t - y).mean():.4f}  RMSE={np.sqrt(((t - y) ** 2).mean()):.4f}")
    for kind in ("single", "double"):
        m = (df["kind"] == kind).to_numpy()
        r2k = 1 - ((t[m] - y[m]) ** 2).sum() / ((t[m] - t[m].mean()) ** 2).sum()
        print(f"   {kind}: R2={r2k:.4f}  MAE={np.abs(t[m] - y[m]).mean():.4f}  n={m.sum()}")

report("voltage", "mixed_voltage", "U")
report("energy", "mixed_energy", "free_energy")
```

> 提示：单 toron 的电压/自由能如果也想单测，把 `df` 过滤成 `df[df.kind=="single"]` 再跑，
> 但 `runs/voltage`、`runs/energy_single` 只用过 4 张测试集，参考价值有限，建议以
> `mixed_*` 三个模型为主。
