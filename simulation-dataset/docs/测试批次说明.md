**308 张带参数标签的模拟 POM 灰度图**，用于检验既有模型在新构型上的表现：

- 覆盖完整参数网格（η 30–40、U 0–3.5 V 八档、双 toron 间距 30–75 十档）；

## 4. 标签字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `filename` | str | 图片文件名（对应 `pom_images/`） |
| `eta` | int | 螺距 η，**仿真晶格单位**，30–40 共 11 类 |
| `U` | float | 外加直流电压 (V)，0.0–3.5 共 8 档 |
| `free_energy` | float | Frank-Oseen 自由能标签 (J)，对该图构型体积积分所得，量级 ~1e-13 |
| `kind` | str | `single` / `double` |
| `n_torons` | int | 1 / 2 |
| `separation` | float | 双 toron 中心间距（晶格单位，30–75）；单 toron 行留空 |
| `R` | float | 该图 ansatz toron 半径（格子单位） |
| `B` | float | 该图 ansatz 扭转壁宽度参数 |

`R`/`B` 为追溯用元数据；按列名取数即可，多出的列不影响既有读取逻辑。

## 5. 参数覆盖

**单 toron（88 张）**：11 个 η × 8 档 U，每格 1 张；w1 / w2 按 `(η + U索引)` 奇偶交替，各 44 张。

**双 toron（220 张）**：11 个 η × 10 档间距 × 2 个电压（每个 η 20 张）；
间距索引 `si` 配对电压 `U[si]` 与 `U[(si+4) % 8]`，因此 8 档电压各出现 20–30 次，
10 档间距各 22 次；w1 / w2 按 `(η + si)` 奇偶交替。

**合计**：`88 + 220 = 308` 张，混合表 308 行。

## 6. 生成方法（报告可直接引用）

> 与既有数据同源：论文 Eq.(3)–(6) 解析 ansatz + 手性扭转 `q0·(z−Cz)` 注入 +
> 经验电压扰动 `|nz|·(1−0.15·(U/3.5)²)` + Frank-Oseen 体积积分（Eq.1）+
> Jones 矩阵正交偏振 POM 成像（λ = 500 nm，Δn = 0.06）。**未运行 PDE 松弛**。
> 本批次仅在 ansatz 几何参数 `(R, B)` 上取新值以生成全新构型，并对每个新构型
> 重新积分自由能。

| 参数 | 值 |
|---|---|
| 仿真盒子 L × Lz | 300 × 32 格（物理 94 μm × 10 μm，1 格 = 0.3125 μm） |
| ansatz R / B | w1 = 13.9 / 0.48；w2 = 14.9 / 0.52 |
| 弹性常数 | K1 = K3 = 17.2e-12 N，K2 = 7.51e-12 N |
| 光学 | Δn = 0.06，λ = 500 nm，正交偏振 |
| 网格 | η ∈ {30…40}，U ∈ {0, 0.5, …, 3.5} V，sep ∈ {30, 35, …, 75} |
| 随机性 | 无（确定性参数网格，`SEED=20261026` 仅作记录） |

**表述规范**（沿用项目口径）：

- 正确：「在 ansatz 几何参数 (R, B) 上做小幅变异生成新构型，对每个新构型做
  Frank-Oseen 体积积分作为标签」；
- 错误：「得到 Frank-Oseen 极小化的自由能」「复现 PDE 松弛平衡态解」。

## 8. 使用注意

1. **只做测试**：不并入训练/验证/划分表，不用于选型；
2. 预处理必须复用 `cnn-inversion/src/data.py` 的 `load_image()`（/255 + 每图 z-score）；
3. 回归模型输出为标准化值，需用 `runs/mixed_voltage/meta.json`、
   `runs/mixed_energy/meta.json` 的 `label_mean`/`label_std` 反变换；
4. 分类类别表取 `runs/mixed_pitch_final/meta.json` 的 `classes`；
5. η 为仿真晶格单位，不可直接标 μm；自由能为积分值而非平衡态自由能；
6. 本批 `(R,B)` 与训练分布不同，指标下降属预期的"新构型泛化"结果。
